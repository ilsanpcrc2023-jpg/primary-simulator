## 변경 사항 (5 커밋)

### 1. P 카드 공단지급 보조숫자 + 수식 박스 (`9c51c33`)

**문제**: 일차의료수가(P) 한 숫자만 노출 → "의원이 P 전액을 받는다"는 오해 우려.

**해결** (`src/components/RegistrationPanel.jsx` TCard):
- 환자군별 카드를 2단 구조로 분리:
  - 상단: **일차의료수가** (P, indigo)
  - 하단: **공단지급** (B×(1−L)+F, rose) — dashed 분리선으로 구분
- 카드 하단에 수식·설명 박스 추가:
  - `공단지급 = B×(1−L) + F` · "일차의료수가에서 타원이용비중만큼 차감 후 지급"
  - `의원 수입 = 공단지급 + 본인부담`

### 2. 모바일 파이 차트 클리핑 수정 (`1084200`)

**문제**: Shared Saving 탭, 모바일(375px)에서 절감액 배분 파이 차트의
"공단 적립"·"일차의료 지원" 라벨이 좌우 양측에서 잘림.

**해결** (`src/components/TabSharedSaving.jsx`):
- 외부 라벨을 내부 % 라벨로 변경 (`label={({ percent }) => ...}` + `labelLine={false}`)
- 범례를 `flex-wrap`으로 줄바꿈 허용
- 컬러 박스에 `shrink-0` 적용 (찌그러짐 방지)

### 3. P·공단지급 글씨 크기 균형 + 색상 분리 (`9bc7fc9`)

**문제**: 1차 작업 후 사용자 피드백 — "공단지급 글씨가 작으니 숨기는 것 같은 느낌".

**해결** (`src/components/RegistrationPanel.jsx`):
- P와 공단지급을 동일 크기 (`text-sm sm:text-base font-extrabold`)로 통일
- 색상으로만 위계 차등: P = indigo-900 / 공단지급 = rose-700
- "공단지급" 라벨을 값 위에 배치하여 분리 효과 + 동일 크기 유지

### 4. 환자수 프리셋 8개 → 3개 (`b66237e`)

**문제**: 참여 전·후 환자수 선택 버튼 8개(1k·1.5k·2k·3k·4k·5k·7k·10k)가 너무 많음.

**해결** (`src/components/RegistrationPanel.jsx` RegScaleCard):
- 핵심 시나리오 3개만 유지: **3,000 · 5,000 · 7,000**
- 그 외 값은 NumBox 직접 입력으로 처리

### 5. L 카드를 P 카드 앞으로 이동 (`440dbaf`)

**문제**: L 변화율이 P 카드의 공단지급(B×(1−L)+F) 계산에 들어가는데
순서상 P 카드 뒤에 있어 인과 관계가 시각적으로 역행.

**해결** (`src/components/TabSimulation.jsx`):
- 카드 순서: ③ F → **④ L 변화율 → ⑤ P 카드** → ⑥ KPI
- 코멘트 추가: "L이 P 카드의 공단지급 계산에 영향 → 먼저 배치"
