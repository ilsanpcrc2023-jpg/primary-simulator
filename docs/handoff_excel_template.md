# 인계장 — 공단 분석가용 엑셀 템플릿 재설계 (claude.ai 웹 세션)

**작성일**: 2026-04-21
**목적**: 공단 서버에서 분석하는 전문가가 시뮬레이터 입력에 필요한 최소한의 데이터를 산출하도록, 복잡했던 기존 엑셀 템플릿을 단순화하여 재설계.
**대상 세션**: claude.ai 웹 채팅 (파일 업로드 지원)

## 배경 — 현재 상태

### 시뮬레이터 (NHIS-HCC 기반 일차의료 지불모형)
- URL: https://primary-simulator.vercel.app/
- 저장소: https://github.com/shleefm/primary-simulator
- 현재 버전: v6.2.3 (2026-04-21 시점, 태그 v6.3 예정)

### 문제 상황
1. **기존 공단 공표 엑셀**이 복잡 — 분석가가 어떤 값을 어떻게 뽑아야 할지 설명이 많이 필요
2. **기존 분석 템플릿** (이전 claude.ai 세션에서 만든 것)도 산만 — 시트 여러 개, 중복 계산, 설명 흩어짐
3. 결과: 분석 전문가에게 일일이 설명·재확인 필요 → 반복 실패

### 해결 목표
- **단일 시트**에 **꼭 필요한 필드**만 배치
- 수식은 엑셀 기본 함수(+, −, *, /, SUM, ROUND)로만 구성 — VBA·매크로·LOOKUP 지양
- 산출 공식은 **표 아래 주석**으로 간단히 설명
- 시뮬레이터에 그대로 붙여넣거나 업로드할 수 있도록 컬럼 구조 일치

## 시뮬레이터가 필요로 하는 데이터 (최소 집합)

시뮬레이터 `편집 테이블`의 현재 컬럼 = 분석가가 산출해야 하는 값:

| 필드 | 기호 | 설명 | 산출 방법 (공단 DB 기준) |
|---|---|---|---|
| 환자군 | g | HCC 기반 4군 (1~4군) | HCC 등급 기준 4분위 |
| HCC 평균 | ref | 환자군별 1인당 연간 의료비 (전체 의료기관 합계) | `SUM(진료비) / COUNT(DISTINCT 환자)` per group |
| 의원비중 | cr | 의원급 외래 비중 (0~1 소수) | `SUM(의원급 외래 진료비) / SUM(전체 의료비)` per group |
| L (타원이용비중) | L | 비용 기반 타원 이용 비중 (0~1 소수) | `(C − M) / C` · C=전체 의원외래비용, M=등록의원 외래비용 |
| M1 | M1 | 1인당 현행 등록의원 외래비 (원/년) | `SUM(등록의원 외래 진료비) / COUNT(DISTINCT 환자)` per group |
| N | N | 환자군별 실인원 환자수 (전체) | `COUNT(DISTINCT 환자 ID)` per group |

**자동 산출 (시뮬레이터가 수식으로 계산 — 분석가 제공 불필요)**
- **B** (환자군 기본수가) = `ref × cr`
- **P** (일차의료수가) = `B + F`
- **공단지급** = `B × (1 − L) + F`

**정책 입력 (시뮬레이터에서 조정 — 분석가 제공 불필요)**
- F (일차의료 기능보정): 환자군별 차등 기본 1/2/3/4만원
- regDist (등록 분포): 의원당 환자군별 등록환자수 (현재 시뮬레이터 default [100/600/200/100])
- M_clinics: 사업 참여 의원 수
- LC: L 변화율 (%p)

## 제안 엑셀 템플릿 구조 (단일 시트)

### 레이아웃

```
┌─────────────────────────────────────────────────────────────────┐
│ [제목 셀] NHIS-HCC 일차의료 지불모형 시뮬레이터 — 분석 템플릿 v1   │
│ [설명 셀] 각 셀에 값 입력 후 시뮬레이터에 업로드 또는 복사-붙여넣기  │
├─────────────────────────────────────────────────────────────────┤
│ [산출 기간] 2023-01-01 ~ 2023-12-31    [분석자] ___________       │
├─────────────────────────────────────────────────────────────────┤
│  환자군  │  HCC 평균  │  의원비중  │  L   │  M1   │  N  │  B  │  │
│  1군    │   400,538 │   0.701   │0.798 │62,801 │11956│(수식)│  │
│  2군    │   642,819 │   0.655   │0.793 │84,083 │13778│(수식)│  │
│  3군    │  1,246,438│   0.589   │0.794 │138152 │18089│(수식)│  │
│  4군    │  3,495,599│   0.299   │0.772 │233560 │25781│(수식)│  │
│  합계   │  ─        │  ─        │ ─    │ ─     │69,604│ ─ │  │
├─────────────────────────────────────────────────────────────────┤
│ ※ B = HCC 평균 × 의원비중  (자동 산출)                            │
│ ※ P = B + F (일차의료수가, F는 시뮬레이터에서 환자군별 차등 설정)   │
│ ※ 공단지급 = B × (1 − L) + F                                     │
└─────────────────────────────────────────────────────────────────┘
```

### 핵심 원칙

1. **한 시트, 한 표**
2. **수식 셀은 B만** (= `HCC평균 셀 × 의원비중 셀`)
3. **모든 입력 셀은 연한 노랑, 수식 셀은 연한 회색**
4. **표 아래 3줄 주석**으로 수식 정의
5. **분석자 기본 정보** (성명·산출일·데이터 기간) 상단 1-2줄 공간
6. **헤더명은 시뮬레이터와 정확히 일치** — `환자군`, `HCC 평균` (또는 `기준의료비` alias), `의원비중`, `L`, `M1`, `N`
   - 시뮬레이터 파일 `src/constants.js`의 `COL_ALIASES` 참고

### 엑셀 업로드 호환

시뮬레이터는 `data/presets/2023.json` 구조로 파싱함:
```json
{ "base": [{ "ref": 400538, "cr": 0.701, "N": 11956, "M1": 62801, "L": 0.7975 }, ...] }
```

`src/hooks/useSimulator.js` 엑셀 파서는 SheetJS가 시트 1행을 헤더로 읽은 뒤 `COL_ALIASES`로 매칭:
- `ref`: "기준의료비" / "refCost" / "환자군 기준의료비" / "HCC평균"
- `cr`: "의원비중" / "clinicRatio" / "의원급 외래비중"
- `L`: "타원이용비중" / "L" / "비용기반 L"
- `M1`: "현재외래비" / "M1" / "현행 M1"
- `N`: "환자수" / "N" / "등록환자수"

→ 새 템플릿 헤더로 **"HCC 평균" 또는 "기준의료비"** 중 택1 (둘 다 인식됨). 권장은 **"HCC 평균"** (시뮬레이터 UI 일치).

## claude.ai 웹 세션에 전달할 작업 지시

```
NHIS-HCC 일차의료 지불모형 시뮬레이터의 분석 템플릿 엑셀을 재설계하고 싶습니다.

1. 배경: primary-simulator.vercel.app 에 배포된 시뮬레이터에 업로드할 분석 데이터를
   공단 분석 전문가가 산출할 때 사용하는 엑셀 템플릿입니다.
2. 현재 두 파일을 업로드합니다:
   (a) 기존 공단 공표 엑셀 — 복잡하고 필요 이상의 필드가 많음
   (b) 이전 세션에서 만든 분석 템플릿 — 시트 여러 개로 산만
3. 목표: 단일 시트, 단일 표, 기본 산술 수식만. 설명은 표 아래 주석 1-3줄.
4. 필수 필드 (시뮬레이터와 호환):
   - 환자군 (1~4군, HCC 기반)
   - HCC 평균 (환자군별 1인당 연간 의료비, 원)
   - 의원비중 (의원급 외래 비중, 0~1 소수)
   - L (타원이용비중, 0~1 소수)
   - M1 (1인당 현행 등록의원 외래비, 원/년)
   - N (환자군별 실인원, 명)
   - B = HCC 평균 × 의원비중 (수식 셀)
5. 수식은 표 아래 주석에 다음 형태로:
   - B = HCC 평균 × 의원비중
   - P = B + F (F는 시뮬레이터에서 환자군별 차등 설정)
   - 공단지급 = B × (1 − L) + F
6. 분석자 기본 정보 (성명·산출일·데이터 기간) 상단에 2-3줄 공간.
7. 헤더명은 시뮬레이터와 정확히 일치시킬 것. (업로드 시 자동 파싱)

기존 두 파일의 산만함과 복잡함의 원인을 파악하고, 단순화된 새 템플릿을 xlsx 파일로
제작해 주세요. 필요하면 SQL 쿼리 예시나 산출 절차 짧은 안내서도 별도 txt로.
```
