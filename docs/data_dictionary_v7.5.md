## 의료비 컬럼의 정의 — 모두 "총의료비" (공단지급 + 본인부담)

엑셀 `NHIS-HCC_Simulator_exc_zero_260518.xlsx` 및 시뮬 baseline의 다음 컬럼은 모두
**총의료비**(공단지급분 + 환자 본인부담 합산)로 분석된 값입니다.

| 컬럼 | 정의 | 단위 | 비고 |
|---|---|---|---|
| **A** | 환자군 평균 의료비 (총의료비) | 원/명/년 | 의료비 0원 제외 후 평균 |
| **T** | 환자군별 총의료비 합계 | 원/년 | T = NT × A |
| **B** | 환자군 외래 기준의료비 (의원급) | 원/명/년 | B = A × CR (총의료비 베이스) |
| **CO** | 의원급 외래 의료비 합계 | 원/년 | 공단지급 + 본인부담 |
| **RT** | 등록환자 전체 외래 의료비 (타원포함) | 원/년 | |
| **RC** | 등록환자 등록의원 외래 의료비 | 원/년 | |
| **RO** | 등록의원 외래 의료비 (총합) | 원/년 | M1 fallback 재료 |
| **M1** | 1인당 등록의원 외래비 | 원/명/년 | M1 = RC/RN = RO/RN |
| **PB** | 일차의료 기본수가 (산출) | 원/명/년 | v7.5: PB = B × C1 = B × (1 − L1) (v7.2.3 안정 산식 유지) |

**v7.5 시뮬 산식 (이전 v7.2.3 유지)**:
- 공단지급 = P = B × (1 − L1) + PF
- 의원 수입 = 공단지급 + M1 × 0.30 (본인부담)
- 본인부담률 30% 단일 가정
- L2 효과는 별도 성과급 모듈 (perf_blended)

**v7.5에서 갱신된 부분 (데이터만)**:
- A·M1·CR·L1·NT 4군 모두 새 엑셀값으로 갱신
- INIT_REG_DIST = [201, 198, 294, 307] (RR = RD × 1,000명, largest-remainder)
- 의원당 환자수 4,379 → 4,246명
- 사업 참여 환자수 12,801,143 → 12,411,152명

## v7.5에서 변경하지 않은 것 (산식 보류)

v7.3.0 (PB = M1 × 0.7) 및 v7.4 (공단 지출 ×0.7) 산식 변경은 **후속 작업으로 보류**.
이유: v7.4 시도 후 perf_blended의 본인부담 처리 모순 발견 (C 슬라이더 큰 값 시 환자
본인부담 누락). 옵션 C(perf_blended를 메인 KPI에서 분리, 별도 카드로 노출) 적용 필요.

v7.5는 **데이터 갱신만** 진행하여 정책 발표용 시뮬레이션에 새 baseline 적용.
산식 검토는 별도 후속 세션에서 진행 예정.
