## 의료비 컬럼의 정의 — 모두 "총의료비" (공단지급 + 본인부담)

엑셀 `NHIS-HCC_Simulator_exc_zero_260518.xlsx` 및 시뮬 baseline의 다음 컬럼은 모두
**총의료비**(공단지급분 + 환자 본인부담 합산)로 분석된 값입니다.

| 컬럼 | 정의 | 단위 | 비고 |
|---|---|---|---|
| **A** | 환자군 평균 의료비 (총의료비) | 원/명/년 | 의료비 0원 제외 후 평균 |
| **T** | 환자군별 총의료비 합계 | 원/년 | T = NT × A |
| **B** | 환자군 외래 기준의료비 (의원급) | 원/명/년 | B = A × CR (총의료비 베이스) |
| **CO** | 의원급 외래 의료비 합계 | 원/년 | 공단지급 + 본인부담 |
| **RT** | 등록환자 전체 외래 의료비 (타원포함) | 원/년 | |
| **RC** | 등록환자 등록의원 외래 의료비 | 원/년 | |
| **RO** | 등록의원 외래 의료비 (총합) | 원/년 | M1 fallback 재료 |
| **M1** | 1인당 등록의원 외래비 | 원/명/년 | M1 = RC/RN = RO/RN |
| **PB** | 일차의료 기본수가 (산출) | 원/명/년 | v7.3.0: PB = M1 × 0.7 (공단지급분) |

**핵심 함의 (시뮬 산식)**:
- M1 × 0.7 = **공단지급분** (등록의원 외래)
- M1 × 0.3 = **환자 본인부담** (등록의원 외래)
- 시뮬에서 본인부담률은 **단일 0.3 가정** (환자군별·서비스별 차등 없음)
- 타원(종합병원·상급종합) 본인부담률도 동일 0.3 가정 (정밀화는 후속 검토)

## v7.4 시뮬 산식 정합 원칙

사용자 정책 의도: "본인부담은 시범사업 전후 동일, 변화는 PB·PF에 따른 것만 표시".

| 산식 | v7.3.0 (이전) | v7.4 (정정) |
|---|---|---|
| 의원 수입 baseline | M1 × N (총의료비) | **그대로** (M1 = 공단지급+본인부담) |
| 의원 수입 after (등록) | (M1+PF) × n_reg + M1 × n_unreg | **그대로** |
| 공단 지출 baseline | C1 × N (총 외래비) | **C1 × 0.7 × N** (공단지급분만) |
| 공단 지출 after (등록 외래) | (M1+PF + 타원L2) × n_reg | **(M1×0.7 + PF + 타원L_base × 0.7) × n_reg** |
| 공단 지출 after (비등록) | C1 × n_unreg | **C1 × 0.7 × n_unreg** |
| L2(=포괄관리 지표 C) 효과 | nhi에 섞여 표시 | **별도 모듈 (perf_blended) 격리** |

→ 결과: 의원 수입 변화 = 공단 지출 변화 = +Σ PF × n_reg (정확히 같은 절대값).
   포괄관리성과(L2 변화)는 두 KPI 모두 별도 표시.

## 참고: 데이터 정의 변경 시 후속 작업

A·M1 등의 정의가 향후 "공단지급분만"으로 바뀌면 시뮬 산식의 0.7 곱셈을 모두 제거해야 함.
이 경우:
- PB = M1 (그대로, 이미 공단지급분)
- 의원 수입 = (M1 / 0.7) + PF (본인부담 추정으로 역산)
- 공단 지출 = M1 + PF

현재(v7.4)는 "총의료비" 가정이 확정되어 있어 이 시나리오는 적용 안 함.
