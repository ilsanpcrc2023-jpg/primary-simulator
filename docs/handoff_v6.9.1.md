## 0. 한 줄 요약

3번 탭(성과 배분)의 모든 UI 라벨에서 "절감"을 "변화·성과·체계 지원" 프레임으로 일괄 치환. **공식·계산·변수명 변경 없음 — UI 라벨·부제·결과 부호 표기·색상만 변경**. 의원·정책 모드 양쪽 동일 적용.

## 1. 변경 배경

본 모형의 핵심 메시지는 **포괄적·지속적 진료의 가치 보상**이며, "절감"은 부산물이지 목적이 아니다. 시뮬레이터 UI에 "절감"이 반복 노출되면 의료계 노출 시 다음 두 부정 프레임을 유발한다.

1. **이 제도는 의료비 깎자는 것이라는 인식** — 의원의 자발적 참여 동기 훼손
2. **DRG·억제 보너스 연상** — 통합참조 v6.0 Part 2.3 절대 금지 용어("타원이용 억제 보너스")와 동일한 구조

따라서 시뮬레이터 UI에서만 "절감" 표현을 "변화·성과·가치·체계 지원"으로 통일. 정책 보고서·건정심 자료의 재정 안정 맥락 "절감" 표현은 그대로 유지(코드 식별자·테스트·내부 주석도 동일 원칙).

## 2. 사용자와 합의된 사전 결정 (G 단계 시작 전)

라벨 변경 지시안에 대해 작업자 의견을 먼저 제시한 뒤 사용자 결정 3가지를 받음:

1. **슬라이더 라벨 부호 방향 모호 우려** → 사용자 결정: **(b) 방식**. 라벨은 "변화율"로 두되 NumBox 좌측에 `−` prefix 추가 + 박스 헤더 부제 "(이용 감소 가정 · 양수 입력 = 음(−) 효과)" 명시.
2. **적용 범위** → 사용자 결정: 인계장처럼 **1·2번 탭의 잔존 표현까지 모두 변경** (실제 잔존은 TabTrack.jsx 3곳).
3. **사소한 추가 권장 (섹션 2 결과 박스 빨강 → 회색조)** → 사용자 결정: **모두 적용**. 결과 박스만이 아니라 "기준 토글" 박스의 빨강 톤도 함께 회색조로 톤다운.

#### 음수 부호 처리 (U+2212 일관)
- 신규 헬퍼 [fChangeAuto](../src/components/TabSharedSaving.jsx:8): `v > 0 ? "−${fAuto(v)}" : fAuto(v)` — 0이면 부호 없이.

## 6. 인계장 지시안과의 차이점 (G 단계 작업자가 변경한 결정)

원 지시안에서 다음 항목들에 대해 작업자(G)가 사용자 협의 후 결정을 보강:

1. **슬라이더 라벨 부호 처리** — 지시안은 "절감률 → 변화율"만 명시 → 사용자 협의로 **NumBox 좌측 `−` prefix + 박스 헤더 부제** 방식 채택. 입력 input은 양수 그대로 두고 표시만 음수 prefix(값 0이면 prefix 비움).
2. **섹션 2 색상 톤다운 범위** — 지시안은 "결과 값 표시 −72.5 억원" 음수 부호만 명시 → 사용자 협의로 **결과 박스 + 기준 토글 박스 모두** 빨강 → 슬레이트/회색 톤다운(부정 프레임 차단·정합성).
3. **Hero 박스 산출 공식 라벨** — 지시안 검색 키워드에는 누락 → "사업대상 **절감배분액**" → "사업대상 **성과배분 재원**" 자동 보완.
4. **TabTrack.jsx 잔존 표현** — 지시안의 "전체 검색·치환" 원칙에 따라 1·2번 탭에서도 UI 노출 4곳 모두 정리.
5. **PT 풀네임 동의어 주석 추가** — 지시안은 "PT, Primary care Transformation grant" 명칭 변경만 명시 → 안내 박스 하단에 "「일차의료 확산기금」과 동의어 (통합참조 v6.0 Part 3D.3)" 주석 추가하여 학술/정책 문서 정합성 명시.
6. **코드 식별자·테스트 설명·내부 주석은 보존** — 지시안 명시("변수명·함수명·파일명 유지"). `sharedSaving`, `acuteSaving`, `clinicFromItem`, `derivedMacroPct`, `itemTotal` 등 영문 키 모두 그대로. 코드 주석 내 한국어 "절감"·"Shared Saving"도 정책 표준 용어로 유지.

## 9. 알려진 제한·주의사항

- **NumBox 좌측 `−` prefix는 표시 전용** — 사용자가 NumBox에 음수를 입력하더라도 max(0, ...) 클램프로 양수만 받음. 입력 흐름은 기존(0~30 양수)과 동일.
- **`fChangeAuto` 헬퍼**는 양수 변화액(`saving`)이 들어오는 전제 — 음수 변화액(즉 의료비 증가)은 이번 모형 범위 밖이라 별도 처리 없음. 향후 양/음 양방향 모형으로 확장 시 헬퍼 부호 분기 보강 필요.
- **변수명 잔존**: `acuteSaving`, `emergencySaving`, `ltcSaving`, `itemTotal`, `clinicFromItem`, `derivedMacroPct` 등은 모두 영문 그대로. 코드를 읽는 사람에게 "saving"의 의미는 정책 보고서·건정심 맥락 그대로(재정 안정 = 절감) 유지.
- **회색조 색상 영향**: 섹션 2 토글 박스 active 상태 시각이 빨강(`border-red-400`) → 슬레이트(`border-slate-400`)로 톤다운되어, 빨강 단일 톤 대비 active/inactive 구분이 약간 약함. 시각 명료성 검토 필요 시 슬레이트 진하게 또는 indigo 톤 검토.
