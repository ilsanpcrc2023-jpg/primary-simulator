# v6.7.0 설계 문서 — L1·L2 분리 (선지급 vs 사후 성과급)

**브랜치**: `feature/v6.7-l1-l2-split` (v6.6.0 base)
**작성일**: 2026-04-24
**설계 합의자**: 사용자(센터장) + Claude
**상태**: 설계 확정 · 구현 진입 직전

---

## 1. 배경 — 왜 바꾸는가

현 모델(v6.6)은 `L`(타원이용비중) 단일 축으로 수가를 깎아 공단 실지급을 결정한다. 정책적으로는 두 층이 뒤섞여 있어 소통·인센티브 설계에 한계가 있다.

- **선지급층** — 참여 초기 L은 과거 관측치로 정해지고, 의원 통제 영역 밖
- **성과 조정층** — 사업 기간 중 의원 노력으로 L이 개선되면 그 차분이 보상 대상

v6.7은 이 두 층을 **L1**(선지급 기준, historical)과 **L2**(사후 성과, observed)로 명시 분리한다.

---

## 2. 핵심 수식 (확정)

### 선지급 (수가 본체)
```
P_g = B_g × (1 − L1_g) + F_g       # 환자군별
공단지급 = P                        # 단일화 (별도 축 없음)
본인부담 = M1_g × 0.30             # 불변
```

### 사후 성과 (L2 귀속)
```
성과급_L2 = Σ_g max(0, L1_g − L2) × B_g × n_reg_g × TrackMul
  n_reg_g: 의원당 환자군별 등록환자수 (state.regDist)
  TrackMul: Track A=0, B=0.5, C=1.0
  no-downside: L2 > L1 구간은 0 처리
  공유율 없음 (의원 100% 환원) — Shared Saving과 상이 · 사용자 후속 결정으로 초기 α=0.5 폐기
```

### Shared Saving (분리 유지)
기존 `SS.clinicFromItem` 로직 그대로. **L2 성과급과 재원·귀인 분리**, 지급 시점만 동일 분기에 정산.

### Track 수입 (v6.7 갱신)
```
Track A (FFS): P_A_g = M1_g + F_g                         # L1 미적용
Track B (혼합 50:50): P_B_g = 0.5 × M1_g + 0.5 × P_g     # P_g = B(1−L1)+F
Track C (환자군 모형): P_C_g = P_g                         # L1 완전 적용
```

Track 전환 시 L1 박스·성과급 카드 활성화/비활성화를 UI에서 시각적으로 반영.

```
     - ↩ 초기화

6. 성과급 미리보기 카드              [신규]
     - Σ max(0, L1 − L2) × B × n_reg × TrackMul
     - n_reg 설명 문구 · 의원 100% 환원 명시 (Shared Saving과 상이)
     - Track 별 지급액 미리보기
7. KPI 2카드                         [기존 유지 · 문구 소폭 수정]
...이하 기존 유지
```

### Track 탭

- **Track A 선택 시**: L1 박스·성과급 카드 회색(disabled)
- **Track B 선택 시**: L1 박스 활성, 성과급 × 0.5
- **Track C 선택 시**: 모두 활성, 성과급 × 1.0
- 성과배분 박스 옆에 **성과급(L2) 카드** 배치 — "성과 정산 패키지" 뷰

## 7. 정책 노트 (시뮬레이터 밖)

### L1 Rebasing 권고

미국 ACO·PCF에서 반복 관찰된 **rachet effect** 방지:

- L1은 **3년 주기 재조정**
- 재조정 시 절감액의 일정 비율(예: 50%)만 기준 반영
- "의원이 L을 낮출수록 다음 해 L1 기준이 똑같이 낮아져 성과급 영구 소멸" 구조 회피

정책 문서·의료계 질의 대응용으로 보존. 시뮬레이터에는 미반영(단일 해 기준).

### L2 성과급과 Shared Saving 귀인 분리

- **L2 성과급** — 외래 본인(의원) 집중도 성과 → 의원 행위 직접 반영
- **Shared Saving** — 입원·응급·요양병원 절감 → 의원의 간접 관리 성과

재원 분리, 지급 시점 동일화("성과 정산 패키지" 동시 지급).

### no-downside 설계 근거

- L1=0.7은 낙관적 예측치 → L2가 이를 넘어도 의원 귀책으로 단정 어려움
- 환자 특성 변동(고령화, 중증도 상승) 영향 분리 불가
- 시범사업 참여 유인 최대화 필요
- 차후 본사업 전환 시 대칭 설계로 전환 여지 열어둠
