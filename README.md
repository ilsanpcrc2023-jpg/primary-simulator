# 일차의료 지불체계 시뮬레이터

국민건강보험 일산병원 일차의료개발센터

- **공식 도메인**: https://primarysimulator.kr
- 백업/개발 URL: https://primary-simulator.vercel.app

## 기술 스택
- React 18 + Vite
- Tailwind CSS
- Recharts (차트)
- SheetJS (엑셀 입출력)

## 로컬 실행
```bash
npm install
npm run dev
```

## 빌드
```bash
npm run build
```
